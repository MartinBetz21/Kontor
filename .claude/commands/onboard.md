Set up Kontor for the user's own business. Read ONBOARDING.md and README.md first and follow ONBOARDING.md step by step:

- Interview one topic at a time, in the user's language.
- Never invent a value. Ask again when an answer is unclear; leave fields empty and list them as open when the user does not know.
- Give no tax advice; the user's tax advisor or tax office letter decides.
- Show every JSON before writing it, and write only through the `kontor` CLI (`init`, `einstellungen setzen`, `profil setzen`, `einstellungen logo`, `bank konto`, `nummernkreis start`).
- Stop and say so when the situation is not supported (see the table in ONBOARDING.md) or when the user wants to keep books for someone else.
- Finish with `kontor einrichtung` and a short handover list.
